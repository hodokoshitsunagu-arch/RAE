# 百变大侦探核心交互重构：雾港来信

这是基于百变大侦探 6.45.2 包内资源恢复的可运行前端演示。它用原创短案件串起选角、私人读本、搜证、线索与笔记、讨论、多题投票和复盘。布局为桌面/手机适配设计，不是原 App 的像素复刻；其他角色、聊天与语音席位均为本地模拟。

## 运行

当前预览：[http://127.0.0.1:4176](http://127.0.0.1:4176)。服务仅监听本机。

```sh
cd Jubensha/demo
npm start
```

不需要安装依赖、构建工具、账号或后端。也可以使用其他静态服务器托管此目录。页面以 ES modules 加载，需通过 HTTP 打开。默认端口 4176，可用 `PORT=其他端口 npm start`。

## 试玩路线

1. 点击“进入房间”，选角色、准备，再开始读本。
2. 阅读故事、秘密、任务三段，逐段标记完成。
3. 自我介绍可发本地消息，然后进入地图搜证。
4. 调查三个地点，在线索页搜索、收藏、打开详情；可先保持私有。
5. 线索可记入笔记。笔记支持编辑和双击编辑；公开前明确提示所附线索一并公开。取消确认会保留私有状态。
6. 讨论阶段向模拟角色询问行踪，结合公共证词进入投票。
7. 两道投票题可前后切换；全部答完再提交。提交后不能改票，先等待其他席位；触发“让模拟队友完成投票”后才进入复盘。
8. 刷新会恢复当前浏览器的对局。重新开局需确认，会清空角色、线索、笔记和投票。

## 实现结构

- [model.js](model.js)：唯一对局状态所有者；操作返回成功状态或带 code/message 的预期错误。阶段、调查预算、线索所有权、笔记披露、投票完成条件及存档验证集中在此。
- [data.js](data.js)：原创案件、人物、地图地点、线索和阶段呈现数据。
- [app.js](app.js)：页面、对话框与事件适配；用户文本转义，输入不直接插入 HTML。投票草稿是暂态 UI 选择，提交后的答案归 model 所有。
- [styles.css](styles.css)：响应式布局、对比度、焦点与 reduced-motion 支持。
- [server.mjs](server.mjs)：无外部依赖的本机静态服务器；不代理或调用原产品服务。

存档只属于当前浏览器，没有真正的多人授权边界。一个人可以完整体验，但不能把本地模拟当作已恢复的房间服务器或语音系统。
