# 网易狼人杀核心交互前端演示

这是基于 `com.netease.lrs` 2.18.21 APK 静态证据制作的独立本地演示。使用原包头像、身份海报和登录插画，重构核心交互；布局不是像素级还原。原版 Lua 正文仍加密，服务端规则没有恢复。

## 运行

无第三方前端依赖，无需 npm install。启动：

```sh
cd Werewolf/demo
npm run dev
```

打开 http://127.0.0.1:4178 。服务只监听本机；`PORT=4180 npm run dev` 可改端口。浏览器刷新会重新开局。

测试：

```sh
npm test
```

## 体验

默认 7 号位为预言家。先点击“准备”→“开始游戏”→查看并确认身份→推进狼人等待阶段→点玩家头像→“确认查验”→查看好人/狼人结果。继续可经历天亮、逐个发言、投票、遗言及下一夜。

左侧（手机布局在房间下方）可以切换女巫、狼人、猎人、白痴、村民；切换会重新入座。“直接体验一段交互”提供夜间、自己的发言、投票、猎人和结算场景。场景跳转重置状态，是演示入口，不是原游戏功能。

- 狼人：选择非队友目标并确认，狼队友身份只在狼人视角公开。
- 预言家：选其他存活玩家，确认后仅得到阵营结果，写入私密笔记。
- 女巫：选择解药、毒药或不用药；毒药需要头像目标，库存跨夜保留。
- 猎人：死亡技能场景可选择存活目标开枪，或放弃技能。
- 发言：按住按钮显示模拟开麦状态；松开/窗口失焦结束。键盘 Enter 可切换。每位 120 秒，可提前结束；“自动推进其他玩家”每 3 秒推进非本人阶段，轮到本人操作时等待。
- 投票：选目标→确认；可以弃票。票型保留每一天/轮的投票者与目标。
- 标记：非技能选人时点头像，为自己添加金水、查杀、好人、狼人或待观察笔记。
- 出局：转为观战，失去常规投票和发言操作；保留查看记录/身份能力。猎人的死亡技能是例外。
- 结算：到胜负确定后公开全部身份。

## 独立演示规则与限制

固定 12 人，4 狼 + 预女猎白各 1 + 4 村民；夜间按狼人→预言家→女巫推进。好人清空狼人获胜，狼人清空神职或村民一侧获胜。平票再投一次，二次平票无人放逐；女巫不能自救、每夜至多用一药；猎人被毒杀不得开枪；白痴首次投出翻牌留场且失去票权。这些由本地 reducer 定义，**不是逆向恢复的网易规则**。

其余席位采用预设发言、公开怀疑顺序和模拟票型，不是学习型 AI 或真实玩家。没有警长竞选、真实麦克风、RTC、账号、网络协议、服务器恢复或联网多人对局。前端内存必然包含完整模拟状态；显示投影用于演示信息隔离，不提供安全的多人后端。

## 代码与素材所有权

- `game.mjs`：唯一状态与规则 owner；不可变转换、选人/票权、技能资源、结算、对玩家的显示投影。
- `app.mjs`：渲染与操作；不另行解释胜负或技能判定。
- `server.mjs`：只提供 demo 目录内静态文件。
- `assets/sources.json`：演示 PNG 到静态导出来源及原包素材 provenance 的映射。
- `tests/game.test.mjs`：19 项状态机及完整一轮流程验证。
- `qa.json`：本次浏览器验证范围；截图为静态留档。
